# Our First Month 💖

เว็บไซต์พิเศษสำหรับวันครบรอบ 1 เดือน โปรเจกต์นี้เขียนด้วย **HTML, CSS, JavaScript** และใช้ **Vite + Tailwind CSS** เป็นระบบเบื้องหลัง เพื่อรองรับเอนิเมชันสวยงามและการอัปโหลดขึ้นเซิร์ฟเวอร์แบบง่ายๆ

🔗 **ลิงก์เว็บไซต์ออนไลน์:** [https://simai66.github.io/OurFirstMonth/](https://simai66.github.io/OurFirstMonth/)

---

## 🛠 วิธีแก้ไขข้อความบนเว็บไซต์

ถ้าคุณต้องการเปลี่ยนคำพูด หรือเพิ่มประโยคใหม่ๆ เพื่อบอกความรู้สึก สามารถทำได้ง่ายๆ ตามนี้ครับ:

1. เปิดไฟล์ `index.html` (ไฟล์ตัวนอกสุด ห้ามแก้ในโฟลเดอร์ `dist` เด็ดขาด)
2. เลื่อนหาข้อความที่เป็นภาษาไทยในไฟล์ แล้วลบ/พิมพ์คำใหม่ลงไปแทนที่ได้เลย (เช่น หาคำว่า *"หนึ่งเดือนที่ผ่านมา..."*)
3. เมื่อแก้ไขเสร็จแล้ว **อย่าลืมกด Save (บันทึก)**

---

## 🚀 วิธีรีวิวก่อนนำขึ้นเว็บ (ดูแบบออฟไลน์)

หากแก้ไขแล้วอยากดูว่าหน้าตาเป็นยังไงก่อนจะส่งขึ้นเว็บจริง ให้ทำดังนี้:

1. เปิด Terminal ในโฟลเดอร์รหัสโปรเจกต์นี้
2. พิมพ์คำสั่ง:
   ```bash
   npm run dev
   ```
3. กดที่ลิงก์ที่แสดงใน Terminal (มักจะเป็น `http://localhost:5173`) เพื่อดูผลลัพธ์บนเครื่องตัวเอง

---

## 🌐 วิธีนำขึ้นเว็บไซต์จริง (Deploy)

เมื่อมั่นใจว่าข้อความทั้งหมดถูกต้อง และอยากอัปเดตเว็บที่อยู่บนลิงก์ออนไลน์ ให้ใช้เพียงคำสั่งเดียว!

1. เปิด Terminal
2. พิมพ์คำสั่ง:
   ```bash
   npm run deploy
   ```
3. รอระบบทำงานประมาณ 10-20 วินาที เมื่อมีคำว่า `Published` แปลว่าเสร็จเรียบร้อย
4. รออีกประมาณ 1-3 วินาที แล้วลองรีเฟรชลิงก์ [หน้าเว็บไซต์จริง](https://simai66.github.io/OurFirstMonth/) แบบออนไลน์ได้เลยครับ 🎉

---

### โครงสร้างไฟล์สำหรับนักพัฒนา

- `/index.html`: ไฟล์หลักที่เก็บโค้ด HTML ทั้งหมดของหน้าเว็บ (แก้ไขคำตรงนี้)
- `/package.json`: ตัวจัดการคำสั่งต่างๆ (เช่น `deploy`)
- `tailwind.config.js`: ไฟล์ตั้งค่า Tailwind CSS (เช่น โทนสี อนิเมชัน)
- `vite.config.js`: ไฟล์ตั้งค่าเชื่อมต่อกับระบบ Build และ GitHub Pages
- `/dist`: โฟลเดอร์ที่รวมไฟล์พร้อมใช้งาน (ห้ามแก้โค้ดในนี้ เพราะจะถูกลบและเขียนทับใหม่ตลอดเวลา Deploy)
